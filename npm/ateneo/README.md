# Ateneo

**Archivo de Tesis, Ensayos, Notas, Ediciones y Obras**

Repositorio institucional de acceso abierto, escrito en Rust. Una alternativa moderna a DSpace: se instala con un comando y se personaliza desde el navegador.

> En desarrollo. Hecho en Ecuador, la Mitad del Mundo.

## Instalación (próximamente)

    pnpm add -g ateneo
    ateneo init

## Apoya Ateneo

Ateneo es y será siempre **gratuito y de código abierto** (AGPL-3.0).
Usarlo no obliga a nada: no hay versión pagada, funciones bloqueadas
ni pedidos de dinero dentro del programa.

Quien quiera ayudar a que el proyecto siga creciendo puede hacerlo así:

- ⭐ Dar una estrella al repositorio en GitHub.
- 🐛 Reportar errores o sugerir mejoras en los [issues](https://github.com/ateneo-rs/ateneo/issues).
- 🌎 Ayudar a traducir Ateneo a otros idiomas.
- 📖 Mejorar la documentación o escribir una guía.
- 🏛️ Contar si su institución usa Ateneo: ayuda a mostrar que funciona.
- 💬 Recomendarlo a otras instituciones.
- 💻 Contribuir con código (ver [CONTRIBUTING.md](https://github.com/ateneo-rs/ateneo/blob/main/.github/CONTRIBUTING.md)).

**¿Dudas o problemas?** Se pueden preguntar gratis en los
[issues](https://github.com/ateneo-rs/ateneo/issues).

**¿Una institución necesita que alguien instale o migre Ateneo por ella?**
Eso es un servicio aparte, con contrato. Puede escribir al equipo del
proyecto para conversarlo.

El nombre y el logo de Ateneo tienen su propia política de uso:
[TRADEMARK.md](https://github.com/ateneo-rs/ateneo/blob/main/TRADEMARK.md).
